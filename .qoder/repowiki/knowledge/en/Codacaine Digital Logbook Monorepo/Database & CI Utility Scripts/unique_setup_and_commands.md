Requires `npm install` in `scripts/` to resolve `dotenv` and `pg`. `DATABASE_URL` must be set (loaded from `.env` in the repo root, `services/project-service/`, or `frontend/`). `backup.js` requires `pg_dump` on PATH; `restore.js` requires `pg_restore`; `migrate.js` connects directly via `pg`. Run via `node scripts/<script>.js [args]` (e.g. `node scripts/migrate.js migrate|status|bootstrap`, `node scripts/backup.js [output.dump]`, `node scripts/restore.js [input.dump]`).
