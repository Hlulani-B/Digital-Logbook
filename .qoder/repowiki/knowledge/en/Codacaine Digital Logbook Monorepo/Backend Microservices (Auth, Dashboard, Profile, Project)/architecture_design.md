Each subdirectory under `services/` is a self-contained npm package with its own `package.json`, `.env`, and entry point (`src/index.js`), running as a separate process on a dedicated port (auth: 4001, dashboard: 4002, project: 4003, profile: 4004). Services share no runtime code; they communicate only via HTTP to the frontend or to each other through distinct endpoints. The common internal layout per service is: `src/Routes/` (Express route modules mounted under `/service`), `src/functions/` (business logic handlers), `src/config.js` (environment loading), `src/db.js` (database client — Supabase SDK for auth-service, `pg` for others), and `src/__tests__/` + `src/__mocks__/db.js` for Jest tests. The project-service additionally exposes an OpenAPI/Swagger UI at `/api-docs` from `docs/openapi.yaml`, mounts a global JWT middleware (`src/middleware/auth.js`) before all `/service` routes except the public notification trigger, and includes background workers (`functions/daemon.js`, `functions/notifications/`, `functions/notes/store.js`).
