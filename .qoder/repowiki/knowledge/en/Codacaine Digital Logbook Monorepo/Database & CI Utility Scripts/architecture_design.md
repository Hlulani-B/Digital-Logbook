A flat collection of independent Node ESM scripts under `scripts/`, each a self-contained CLI with its own `main()` entry point. `backup.js` and `restore.js` are thin wrappers around the external `pg_dump` / `pg_restore` binaries: they load `DATABASE_URL` from `.env` files (current dir, `services/project-service/.env`, `frontend/.env`), validate that the PostgreSQL client tools are installed, then invoke them via `execFileSync` with flags scoped to the `public` schema (`--no-owner`, `--no-acl`). Backups are stored as custom-format `.dump` files in `scripts/backups/`, named with ISO timestamps. `migrate.js` is the only script that connects directly to PostgreSQL via the `pg` library; it discovers `.sql` files in `supabase/migrations`, tracks applied versions in a `public.schema_migrations` table (version + SHA-256 checksum prefix), and exposes three commands — `migrate`, `status`, `bootstrap` — dispatched by `process.argv[2]`. Each migration runs inside an explicit `BEGIN`/`COMMIT` transaction so failures roll back atomically. `generate-badges.js` reads `coverage-summary.json` from each service under `services/<service>/coverage/` and writes shields.io-style SVGs to `badges/<service>/<metric>.svg`. All scripts use dynamic `import('dotenv')` so the dependency is optional at import time and only loaded when needed.
