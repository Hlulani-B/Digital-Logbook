Each file is a self-contained React page component mounted by the router (e.g. `/project/:projectName`, `/dashboard`, `/timeline`). Data loading follows a consistent cache-first pattern: pages read from `@/lib/cache` (`CACHE_STORES.PROJECTS`, `CACHE_STORES.ENTRIES`, `CACHE_STORES.ALL_ENTRIES`) via `cacheGet`, subscribe to cache updates with `cacheSubscribe`, and fall back to `syncAllData(email)` on first visit; overlapping async loads are guarded by per-call sequence counters stored in `useRef`. Project-level state lives in these pages while reusable entry UI is delegated to shared components: `EntryBox` (NewEntry.tsx) renders individual items, `AddEntry` (AddEntry.tsx) is the modal form for creating entries, and view modes (cards/table/checklist/board) are rendered by template components under `@/Templates/...` (`ProjectTaskTable`, `EntriesByDueDateBoard`, `ChecklistView`). Cross-cutting concerns are pulled in via context/hooks (`useAuth`, `useNotes`, `useNetworkStatus`) and side effects like recently-viewed tracking (`trackViewedProject`, `trackCreatedEntry`). Navigation between project list, detail, archives, timeline and all-entries is handled through `react-router-dom`'s `useNavigate` and route params.
