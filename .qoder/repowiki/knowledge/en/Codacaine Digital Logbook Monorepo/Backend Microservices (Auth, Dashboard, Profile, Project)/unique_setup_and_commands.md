Each service requires its own `.env` file containing `SUPABASE_URL`, `SUPABASE_KEY`, and a unique `PORT`; run with `npm start` (or `node src/index.js`) per service. Tests use Jest with Babel transpilation (`babel-jest`), coverage via `npm run test:coverage`, and integration tests rely on `supertest`. The project-service also ships helper scripts in `scripts/` (e.g. `regenerate-summaries.js`, `backfill-summaries.js`) and a `curl_tests.sh` for manual endpoint verification.
